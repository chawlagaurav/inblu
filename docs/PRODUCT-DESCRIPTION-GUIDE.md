# Product Description Formatting Guide

This guide explains how to format product descriptions with bold text, bullet points, numbered lists, and more.

---

## Quick Reference

| Format | How to Write | Result |
|--------|--------------|--------|
| **Bold** | `**your text**` or `__your text__` | **your text** |
| *Italic* | `*your text*` or `_your text_` | *your text* |
| Bullet List | Start line with `- ` | • item |
| Numbered List | Start line with `1. ` | 1. item |
| Subheading | Start line with `#### ` | Section title |

---

## Detailed Examples

### 1. Bold Text

Use double asterisks `**` or double underscores `__` around text to make it bold.

**How to write:**
```
The **InBlu Carbon Block Filter** provides __superior filtration__ for your home.
```

**Result:**
> The **InBlu Carbon Block Filter** provides **superior filtration** for your home.

---

### 2. Italic Text

Use single asterisks `*` or single underscores `_` around text for italics.

**How to write:**
```
This filter is *recommended* for households with _hard water_.
```

**Result:**
> This filter is *recommended* for households with *hard water*.

---

### 3. Bullet Points (Unordered Lists)

Start each line with a dash `-` followed by a space.

**How to write:**
```
Key Features:
- Removes chlorine and bad taste
- Reduces sediment and particles
- Long-lasting 6-month lifespan
- Easy DIY installation
```

**Result:**
> Key Features:
> - Removes chlorine and bad taste
> - Reduces sediment and particles  
> - Long-lasting 6-month lifespan
> - Easy DIY installation

---

### 4. Numbered Lists (Ordered Lists)

Start each line with a number, period, and space (e.g., `1. `).

**How to write:**
```
Installation Steps:
1. Turn off water supply
2. Remove old filter cartridge
3. Insert new InBlu filter
4. Turn water back on and flush for 5 minutes
```

**Result:**
> Installation Steps:
> 1. Turn off water supply
> 2. Remove old filter cartridge
> 3. Insert new InBlu filter
> 4. Turn water back on and flush for 5 minutes

---

### 5. Subheadings

Use `####` at the start of a line (with a space after) to create a subheading.

**How to write:**
```
#### Product Specifications

Width: 50mm
Height: 250mm

#### What's Included

- 1x Filter cartridge
- 1x O-ring seal
- 1x Installation guide
```

**Result:**
> #### Product Specifications
> Width: 50mm  
> Height: 250mm
>
> #### What's Included
> - 1x Filter cartridge
> - 1x O-ring seal
> - 1x Installation guide

---

### 6. Combining Formats

You can combine multiple formats together.

**How to write:**
```
**InBlu Premium Carbon Block Filter**

The *ultimate solution* for clean, fresh-tasting water.

#### Key Benefits

- **99% Chlorine Removal** - Enjoy pure tasting water
- **Sediment Filtration** - Removes particles down to _5 microns_
- **Long Life** - Lasts up to **6 months** or 10,000 litres

#### Technical Specifications

1. Filter Type: Carbon Block
2. Flow Rate: 2L/min
3. Dimensions: 50mm x 250mm

**Note:** Replace filter when water flow decreases significantly.
```

## Tips for Great Product Descriptions

1. **Start with a strong opening** - Use bold for the product name and a compelling first sentence

2. **Use bullet points for features** - Easy to scan and read

3. **Include specifications** - Customers want to know the details

4. **Highlight key benefits** - Use bold to draw attention to important points

5. **Keep paragraphs short** - 2-3 sentences maximum

6. **Use subheadings** - Break up long descriptions into sections

---

## Common Mistakes to Avoid

❌ **Don't forget the space** after `-` or `1.` for lists
```
-No space here won't work
- Space here will work ✓
```

❌ **Don't mix formats incorrectly**
```
**Bold with *italic* inside** - This works ✓
*Italic with **bold** inside* - This works ✓
**Bold with no closing - Won't work ❌
```

❌ **Don't use too many formats** - Keep it clean and readable
